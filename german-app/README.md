# BLFRT Schule — курс немецкого A1-B2

Персональное офлайн-приложение для изучения немецкого языка с нуля до уровня B2.

## Запуск

Просто откройте `index.html` в браузере, либо поднимите локальный сервер:

```bash
npx serve german-app
```

## Статус наполнения данных

- ✅ Архитектура приложения (уроки, словарь, грамматика, аудирование, разговорник, тесты, тренировка дня, геймификация, «Мои карточки», «Экзамен», «Методичка»).
- ✅ Словарь: 3800 слов — A1: 800, A2: 1000, B1: 1200, B2: 800 (10 тем × 80 слов).
- ✅ 300 диалогов (по 10 на каждую из 30 тем A1/A2/B1).
- ✅ Грамматический справочник — 39 тем (A1: 11, A2: 8, B1: 10, B2: 10) с таблицами, мнемониками и примерами.
- ✅ Методичка — полный связный учебник немецкого языка, 24 главы: от общей картины языка и произношения до местоимений, числительных, словообразования, приставок глаголов, управления глаголов, инфинитивных конструкций, пассива, пунктуации, деловой переписки и частых ошибок русскоговорящих. Можно читать подряд как книгу.
- ✅ Раздел «Экзамен» (B1-B2) — чтение длинных текстов с вопросами, письмо по заданию с образцами ответов, говорение с таймером и записью голоса.
- ✅ «Мои карточки» — личная колода с добавлением своих слов и слов из словаря, интервальные повторения (SM-2), как в Anki.
- ✅ PWA: устанавливается на телефон, работает офлайн, резервное копирование прогресса в файл.

**Итого: 3800 слов, 300 диалогов, 39 грамматических тем, 24 главы методички — курс полностью охватывает путь от A1 до уверенного B2.**

## Технологии

Vanilla HTML/CSS/JS, Web Speech API (озвучка + распознавание), localStorage, SM-2 интервальные повторения, PWA (manifest + service worker), без внешних API.
